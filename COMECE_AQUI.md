# Comece aqui

Calculadora de margem para Amazon, Mercado Livre, Magalu, Shopee e SHEIN — do
[Henrique Niada](https://instagram.com/henriqueniada).

Roda na sua máquina. Não tem cadastro, não tem senha, não precisa de internet para calcular.

## 1. Instale o Node.js

Baixe em <https://nodejs.org> (a opção LTS) e instale normalmente.

## 2. Abra o terminal nesta pasta e rode

```bash
npm install
npm run dev
```

## 3. Abra o endereço que aparecer

Normalmente <http://localhost:5173>. Na primeira vez, um tour guiado explica a tela inteira.

---

**Prefere não usar o terminal toda vez?** Rode `npm run build` uma vez: a pasta `dist/` que
aparecer tem um `index.html` que abre com duplo clique.
